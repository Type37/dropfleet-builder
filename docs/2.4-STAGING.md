## Needs design

1. **Fleet Space Stations.** Free built-in Features, a number of extra Features
   the station must take, optional Armaments (weapons repeatable, Structures one
   each, Defensive Garrison and Forward Operating Base exclusive), and upgrades
   (Astrobotanical Lab, Defence Grid, or one Feature). The picker today has one
   armament pool and one upgrade pool.
2. **Escort (14.1.6).** Chosen before deployment: an Escort Group is paired with
   one H or C Group and they activate together. Nothing in the list sets a pair.
3. **Shield-X (14.1.16).** A shields token raised at the start of an activation:
   saves replaced, Signature tripled, a Spike after each attack, lost on Silent
   Running. Calculator and play mode have no toggle.

## Ship day (Jet says ship; planned Wednesday 4 November)

Only after TTCombat has published 2.4 on the downloads page.

1. `git fetch`, then rebase local `master` onto `origin/master` (the monthly
   job may have committed there).
2. `python scripts/auto-update.py`. It reads the downloads page, points the
   scripts at the 261104 file names, rewrites `scripts/dfc-files-manifest.json`
   and `scripts/card-snapshots.json`, sets the "Updated <month> with <file>"
   line, adds a What's New entry and raises the `sw.js` cache name. Without
   this the monthly job sees 2.4 as new next month and ingests it again.
   It must finish with the cache name above `dfc-cache-v521`.
3. Check the What's New entry covers the rules too (rulebook 2.4, calculator,
   AP Dice Bonus, Hero, Feature Carriers), not only card changes.
4. Run `node scripts/test-calc-data.mjs`, `test-calc-engine.mjs`,
   `test-calc-rules.mjs`; all must pass.
5. Push. Then check the live site serves the new `sw.js` cache name and the
   menu says the November update.
